=================================================================
  TROUBLESHOOTING
=================================================================

Issue: Provider not receiving notification
-------------------------------------------
1. Backend restarted? (Check terminal for "Started ServiceSpotApplication")
2. Provider logged in? (Check localStorage.getItem('providerEmail'))
3. WebSocket connected? (Console: "WebSocket Connected for user: ...")
4. Review submitted? (Check backend logs for "Sending review notification")
5. Using 2 different browsers? (Required for real-time testing!)

Issue: "No user email found"
----------------------------
1. Logout and login again
2. Check: localStorage.getItem('providerEmail')
3. Should show provider's email
4. If null → clear cache and login again

Issue: Backend not starting
---------------------------
1. Check terminal output
2. Look for "Started ServiceSpotApplication"
3. If error, check port 8080 is not in use
4. Restart: ./mvnw spring-boot:run
