TROUBLESHOOTING
=================================================================

Problem: "No user email found"
-------------------------------
Solution:
1. Logout (navbar button or localStorage.clear())
2. Login again
3. Check localStorage.getItem('providerEmail')
4. If still null → clear cache and try again

Problem: WebSocket won't connect
---------------------------------
Solution:
1. Backend running? http://localhost:8080
2. Frontend running? http://localhost:5173
3. CORS enabled? (already configured in WebSocketConfig)
4. Restart both backend and frontend

Problem: Notifications not real-time
-------------------------------------
Solution:
1. Use TWO different browsers!
2. Both must be logged in at same time
3. Both must show "WebSocket Connected" in console
4. Then test booking flow

Problem: Backend says sent but frontend no receive
---------------------------------------------------
Solution:
1. Check emails match:
   - Backend log: "sent to: john@123.com"
   - Frontend console: "Connected for user: john@123.com"
2. If emails don't match → logout and login again
3. Make sure WebSocket subscription is active
