==================================================
  IMPORTANT NOTES
==================================================

1. The default admin account is automatically created
   when the backend application starts.

2. You can login to the admin dashboard at:
   http://localhost:5173/login-admin

3. After successful login, you will be redirected to:
   http://localhost:5173/admin-dashboard

4. The admin can:
   - View all customers and providers
   - Verify/unverify customers and providers
   - Promote customers/providers to admin role
   - Demote admins back to customer/provider role
   - View all services
   - View platform statistics

==================================================
  TESTING THE LOGIN
==================================================

You can test the admin login API directly using:

POST http://localhost:8080/api/admin/login
Content-Type: application/json

{
  "email": "admin@servicespot.com",
  "password": "admin123"
}

Expected Response (200 OK):
{
  "role": "ADMIN",
  "success": true,
  "name": "Admin",
  "id": 1,
  "email": "admin@servicespot.com"
}
